Smart Channels — same trick, different surface

The related-items demo showed the post-roll panel of a single player adapting to the host page. Channels do the same thing, but for a whole page of videos: grids, carousels and featured headers, all driven by smart cliplists with dynamic filters.

What's a Channel?

A Channel is a video sub-site. You drop a small <script> tag into a page and a fully styled video page mounts there — featured slider, multiple carousels / grids, a detail page, optional search bar. Each block can be a static playlist or a smart playlist with dynamic filters.

The smart bit, applied here: a single Cliplist block on a Channel can refill itself per-visitor — based on the URL, on a saved preference, or on a topic an AI just suggested. The host page never re-fetches the channel; the channel re-queries its catalogue on its own.

Quick anatomy

The Channel embed itself is the same one Blue Billywig customers already paste into their pages:

<script src="https://{publication}.bbvms.com/ch/{channelId}.js" async></script>

The Channel widget loads the channel config (a JSON document with blocks: FeaturedHeader, Cliplist, Promotional, Search, …). For every Cliplist block whose cliplist has allowDatasource: true, the Channel re-issues a query against the Blue Billywig search engine with the filter values resolved from the visitor's URL or browser storage. Net effect: the block on the page silently filters itself per visitor.
